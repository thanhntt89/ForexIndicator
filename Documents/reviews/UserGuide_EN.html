RSI Advanced V11.37 — User Guide

A multi-timeframe RSI signal indicator for MetaTrader 4 & 5. It detects 9 setup types from an RSI crossover system, estimates the probability of each target from real historical outcomes, and paints entry, stop-loss and take-profit levels on your chart with a full analytics panel.

Platform: MT4 + MT5 Type: Separate-window indicator Best on: XAUUSD intraday Signal cases: 9

1 Overview

RSI Advanced is built on a classic RSI-crossover engine (a fast RSI line crossing a signal line), extended with Bollinger Bands on RSI, an orange baseline, and a large analytics layer. It does not place trades — it is a decision-support indicator that tells you what the setup is, how good it has performed historically, and where to enter / stop / target.

Signal detection

9 "cases" (bounce, divergence, trend, breakout, crossover…) with a per-timeframe priority order.

Probability engine

3-tier historical simulation estimates the chance of hitting TP1/TP2/TP3 vs. SL, calibrated to real outcomes.

Risk levels

Auto SL/TP (ATR / Fibonacci / Hybrid) plus multi-level entry zones with position sizing.

Multi-timeframe

Reads RSI trend on M5→D1 and warns when the higher timeframe disagrees with your signal.

Self-learning

Logs every signal + outcome to CSV and feeds real win-rates back into the probabilities.

Cross-broker

GMT normalization keeps H4/D1 RSI consistent between brokers on different server times.
The core ideaThe Green line is a very fast RSI (period 2); the Red line is a smoothed signal (period 7). A Green-crosses-Red event is the heart of every signal. The other lines (Bollinger Bands, orange baseline, the 32/50/68 levels) decide which case the crossover belongs to and how strong it is.

2 Installation

The project ships as a main indicator file plus a folder of .mqh include modules. The include folder must sit inside your terminal's Include directory.

File placement

PlatformMain file →Include folder →
MT4MQL4/Indicators/RSI_Advanced.mq4MQL4/Include/RSI_Advanced/*.mqh
MT5MQL5/Indicators/RSI_Advanced.mq5MQL5/Include/RSI_Advanced/*.mqh

Open the terminal's data folder via File → Open Data Folder, then copy the files into the paths above.

Compile & attach

  1. Open MetaEditor (F4 in the terminal).
  2. Open RSI_Advanced.mq4 (or .mq5) and press Compile (F7). It should compile with 0 errors.
  3. Back in the terminal, drag RSI Advanced from the Navigator onto a chart (XAUUSD is the tuned default).
  4. Tick "Allow DLL imports" is not required. Just confirm the inputs dialog and press OK.
Recommended first runAttach to XAUUSD, M15 or M30, leave InpAutoTFConfig = true and InpEnableSignalLog = true (both default). Let it run for a few days so the CSV log accumulates real outcomes — the probabilities become far more meaningful once data builds up.

3 Reading the RSI Window

The indicator draws in a separate window below price, scaled 0–100.

LineMeaningDefault
Green (RSI Fast)Very fast RSI (period 2). The reactive line that generates crossovers.Fast MA = 2
Red (Signal)Smoothed signal line (period 7). Green crossing Red = trigger.Signal MA = 7
Blue (BB Upper / Lower)Bollinger Bands computed on RSI (period 34, dev 1.685). Define "stretched" RSI and breakouts.BB = 34 / 1.685
Orange (Baseline)The RSI baseline / trend reference. Green & Red above orange = bullish bias, below = bearish.Baseline = 34

Horizontal levels

20 / 32 / 50 / 68 / 80 — the reversal/trend reference levels. 32 and 68 are the oversold/overbought thresholds used by the bounce cases; 50 is the trend pivot used by Case 4.

4 The 9 Signal Cases

When a bar closes, the indicator checks patterns in a priority order and fires the first match. Each case has its own probability track record. Family colors below: Reversal Trend Breakout Experimental.

#NameFamilyBUY trigger (SELL is mirrored)
1OB/OS BounceReversalGreen was < 32 & below BB lower, then crosses back above 32 → sellers exhausted.
2Regular DivergenceReversalPrice makes a Lower Low but RSI makes a Higher Low → selling weakening.
3Hidden DivergenceTrendPrice Higher Low but RSI Lower Low → uptrend still intact (continuation).
4Strong TrendTrendGreen crosses above 50 and breaks BB upper → strong momentum starting.
5Orange Near LevelReversalOrange baseline sits near 32 (oversold) while Green crosses up Red.
6Trend ContinuationTrendGreen & Red hold above orange, a pullback is bought back → add/hold.
7Sideway BreakoutBreakoutSeveral crosses inside the bands (range) then Green breaks BB upper.
8Basic CrossoverTrendGreen crosses above Red with a strong angle (the core RSI-Advanced rule).
9Plain CrossExperimentalGreen crosses above Red with no angle gate — captures the weak crosses Case 8 rejects, tracked separately.
Priority & per-timeframe availabilityNot every case runs on every timeframe. Fast timeframes (M1/M5) only run the fast-resolving cases; higher timeframes enable more. See the Timeframe Auto-Config table for exactly which cases are active where. On M1/M5 the scan order is reordered to 6 → 2 → 4 → 3 → 1 → 5 → 7 to favor the setups that historically work best there.
Case 9 is experimentalCase 9 exists to measure whether a bare crossover (with no angle filter) has an edge on your symbol/timeframe. Its arrow is not a trade recommendation by itself — check the panel's probability and the AngIC diagnostic first. Disable with InpEnableCase9 = false if it adds noise.

5 Chart Objects (on the price chart)

Arrows

Lime up-arrow = BUY signal, red down-arrow = SELL, plotted at the signal bar. Arrows are kept for historical reference even when a signal is not actionable.

Entry line

White dotted line at the intended entry price for the active signal.

SL / TP lines

5 horizontal lines: SL, TP1, TP2, TP3 + entry. Computed from ATR/Fibonacci/Hybrid.

Entry zones

Up to 3–5 staggered limit-entry prices (market + pullback levels), each with its own reach probability, R:R and expected value.
Why the lines sometimes disappearWhen the panel's recommendation is WAIT, AVOID, or Counter-Trend, the SL/TP lines, probability labels and entry zones are hidden on purpose to avoid clutter on non-actionable signals. The arrow and the panel stay visible. This is expected behavior, not a bug.

6 The Info Panel

The panel (top-left by default) is the control center. It has two modes.

When no signal is active

Shows market context: server & UTC time + broker GMT offset, the MTF trend row (M5→D1, colored bull/bear/neutral) with aggregate agreement, the volatility regime (ATR ratio, e.g. QUIET / NORMAL / EVENT), and the market regime multiplier.

Recommendation levels

The big header verdict is derived from a 0–100 score (EV + data + MTF + intermarket + walk-forward − spread penalty) combined with EV:

LabelConditionMeaning
STRONG ENTRYscore ≥ 75 & EV > 0.15High-conviction setup.
ENTRYscore ≥ 55 & EV > 0.05Valid setup.
CAUTION ENTRYscore ≥ 35 & EV > 0Marginal — smaller size / confirmation.
WAITEV > −0.05No clear edge; stand aside.
AVOID / AVOID (Counter Trend)otherwiseNegative expectancy, or fighting the higher-TF trend.
The "Low Data" safety gateIf there aren't enough real historical outcomes for the timeframe, any positive verdict is capped down to WAIT, and confidence shows NO DATA (theoretical only) or LOW DATA (n<X). This deliberately prevents over-confidence from the theoretical model before enough evidence exists. It relaxes automatically as the log fills up.

Probability & confidence

Confidence is a 95% margin-of-error on the win-rate given the sample size:

  • HIGH — margin ≤ ±8%
  • MODERATE — ≤ ±15%
  • LOW — ≤ ±25%
  • VERY LOW — > ±25%

7 Timeframe Auto-Config

Auto-Config overrides your manual inputsWhile Auto-Config is on, changing inputs like InpSLRatio, InpTPRatio, InpMinSignalScore or the per-case toggles has no effect — the profile below wins. To tune those by hand, set InpAutoTFConfig = false first.

9 Logging & Quant Analysis

With logging on, three CSV files are written to <terminal>/MQL4(5)/Files/RSI_Advanced_Logs/, one set per symbol/timeframe/year, all joinable on SIGNAL_ID:

# joined by SIGNAL_ID
signals_XAUUSD_M15_2026.csv   # the facts: entry, SL/TP, ATR, RSI-at-signal, session, hour…
scoring_XAUUSD_M15_2026.csv   # the decision: score, rec, prob, EV, R:R, MTF, spread…
outcomes_XAUUSD_M15_2026.csv  # the result: TP/SL hit, bars held, MFE/MAE, P&L pips…

Because outcomes persist to disk, the panel's win-rates survive timeframe switches and terminal restarts — the indicator effectively learns from your own market history.

Zone-edge analysis tool

The bundled Python tool tools/zone_edge.py joins signals + outcomes and reports win% / average P&L / MFE-MAE broken down by case × RSI-zone (OS/MID/OB) × direction — so you can answer questions like "do my oversold BUY crosses actually have an edge?"

# Windows path example — point --dir at your logs folder
python tools/zone_edge.py --dir "C:/Users/You/AppData/Roaming/MetaQuotes/Terminal/<id>/MQL5/Files/RSI_Advanced_Logs"
python tools/zone_edge.py --dir <logs> --symbol XAUUSD --tf H1
python tools/zone_edge.py --dir <logs> --min 20   # only buckets with >=20 resolved trades
Outcome encoding-1 = SL hit · 0 = timeout/pending · 1/2/3 = TP1/TP2/TP3 hit. Win-rate = TP / (TP + SL). This tool is a standalone offline helper — the indicator itself does not require Python.

10 Best Practices

Workflow in one paragraphWait for an arrow. Read the panel header: only act on ENTRY / STRONG ENTRY (or CAUTION with a smaller size). Check that MTF context is SUPPORT/NEUTRAL, confidence is at least MODERATE, and the Win% / EV is positive. Use the entry zones for laddered fills and the SL/TP lines for exits. Skip anything showing WAIT / AVOID / LOW DATA.

Timeframe & session guidance (from the quant log)

  • M1 is mathematically more efficient than M5, but only during the EU–US Overlap session. Case 6 (Trend Continuation) works well; avoid the Asian & late-NY sessions.
  • M5 favors Case 7 (Sideway Breakout) and the London session; Case 7 works poorly on M1 (false ranges).
  • M15 / M30 are the most balanced all-round scalping frames.
  • H1 runs the full case set; H4+ is best used for direction/context rather than fast entries.

Let the data build

  • Keep InpEnableSignalLog = true. New cases (8, 9) and any bucket with few resolved trades will show probabilities pulled toward 50% and may say WAIT (Low Data) — this is intentional anti-overconfidence and relaxes as outcomes accumulate.
  • Re-run zone_edge.py periodically to see which case × zone × session combos truly pay on your broker.
  • Trust the AngIC reading: if it's negative/noise on your TF, the "strong angle" gate is not helping there.

11 FAQ / Troubleshooting

The Green line clearly crossed the Red line, but no arrow appeared.

Most common reasons: (1) the cross happened inside a trend where the adaptive angle threshold is high, so it didn't qualify as a "strong angle" (Case 8); (2) a higher-priority case already fired that bar; (3) the case isn't enabled on this timeframe (see §7); (4) the arrow only prints on a closed bar — a cross on the live bar is confirmed one bar later; (5) the score was below the minimum, or the risk manager is in a cool-down/circuit-breaker state.

Panel says WAIT / LOW DATA / NO DATA even though the setup looks great.

The Low-Data safety gate caps positive verdicts to WAIT until enough real historical outcomes exist for that timeframe. Keep logging on and let it accumulate; it opens up automatically.

I changed InpSLRatio (or a case toggle) and nothing happened.

InpAutoTFConfig = true is overriding it. Set it to false to use manual inputs — see §7.

MT4 and MT5 show different signals on the same symbol/timeframe.

On H4/D1 this is expected when the two brokers use different GMT server offsets: their candles open at different times, so price highs/lows (and therefore divergence cases) differ. GMT normalization aligns the RSI across brokers, but cannot rewrite price data. On M1/M5, small differences come from different price feeds. To compare fairly, use the same broker / GMT offset, and use the panel's UTC clock to confirm you are looking at the same moment.

The SL/TP lines and entry zones vanished.

Expected when the recommendation is WAIT/AVOID/Counter-Trend — see §5. The arrow and panel remain.

The panel shows [BLOCKED].

The risk manager is blocking new entries (max concurrent signals, daily risk, drawdown circuit-breaker, or max trades reached). The signal is still displayed for reference.

EV (R)Expected value per trade, expressed in units of risk (R). Positive EV = profitable on average.
R:RReward-to-risk ratio, e.g. 1:2 means the target is twice the stop distance.
Tier 1 / 2 / 3Three probability sources: T1/T2 = matched historical signals (weighted), T3 = broad ATR-based historical scan.
nEffEffective sample size after similarity weighting — the "real" number of comparable trades.
MTFMulti-timeframe. The higher-TF RSI trend context around your signal.
