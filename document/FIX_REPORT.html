Deviations from Documentation

SLTP.mqh — Partial Selection Sort Instead of Full Sort Replacement

Document recommendation: Replace O(n²) bubble sort with a simple partial selection sort for 3 percentiles (50th, 75th, 90th).

Actual implementation: Used a partial selection sort that sorts up to the k-th element for each target percentile. This is functionally equivalent but the inner loop variable was renamed from b to b2 to avoid shadowing the outer function's b variable in the same scope. This is a minor naming deviation required by MQL4 compiler constraints.

Reason: MQL4 does not allow variable shadowing in the same function scope. The rename was necessary to compile without warnings.
